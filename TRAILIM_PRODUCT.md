# TRAILIM_PRODUCT.md
## Product definition
Trailim is a mobile-first place-based learning platform where students and educators create, field-test, review, publish, and reuse interactive routes, quests, scavenger hunts, community trails, and outdoor learning experiences.

## Strategic core
Trailim is not a generic tourism app and not merely a route builder. Its differentiating workflow is:
Student team → research → route design → real fieldwork → test walk → teacher rubric/review → revision → approval → reusable community asset → later expert/institution verification and maintenance.

## Experiential core
The product must preserve fun and active field experiences:
- riddles, clues, missions
- team challenges and scoring
- QR/passcodes and future GPS triggers
- photo/video/audio evidence
- hidden, optional and bonus stations
- Learning Mode and Challenge Mode
- observation-first and Eyes Up, Screen Down patterns

## First adoption model
1. Assigned experiences from schools, teachers, institutions, events and direct links/QR.
2. Planned discovery by families/groups looking for an activity.
3. Spontaneous Near Me discovery only after enough high-quality local content exists.

## Pilot MVP
- Student/Teacher auth
- organizations/schools
- student teams and roles
- route drafts + RouteVersion at submit/publish
- 2–10 stations
- text/image/video/audio blocks
- MCQ/T-F/open/reflection/photo/code/QR tasks
- QR/passcode; basic contextual GPS optional
- field checklist + test walk
- submit → review → changes → resubmit → approve
- class/school publication
- participant join/progress/completion
- Learning + basic Challenge mode

## Explicitly deferred
Full offline, AR, advanced geofencing, live multiplayer, nationwide discovery dependence, AI route generation, payments/marketplace, full Route Health UI, full Commissioned Challenges UI, full Adopt-a-Route UI.
